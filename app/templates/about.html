About Yousif's Blog

A Feature-Rich Flask Blog Platform

Welcome to My Blog!

This is a full-featured web blog application built with Flask and Python. I created this platform to share thoughts, ideas, and connect with others who share similar interests.

Feel free to explore the site, create an account, and start sharing your own posts!

Core Features
  • User registration and authentication
  • Profile management with custom avatars
  • Create, read, update, and delete blog posts
  • Pagination for efficient browsing
  • Responsive design for all devices
  • Password recovery via email
Technologies Used
  • Python & Flask framework
  • SQLAlchemy for database management
  • Flask-Bcrypt for secure password hashing
  • Jinja2 Templates for dynamic content
  • Bootstrap for responsive design
  • WTForms for form validation
